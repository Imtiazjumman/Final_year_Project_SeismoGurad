🌍 About SeismoGuard

SeismoGuard is an academic IoT capstone project implementing a real-time P-Wave / S-Wave early warning system. The system detects the faster P-wave first using the STA/LTA algorithm on the vertical axis, then issues a warning before the destructive S-wave arrives — giving occupants up to 20 seconds to reach safety.

🔬 P-Wave vs S-Wave Science

⚡ P-WAVE (Primary)

Speed: ~6–8 km/s
Motion: Compressional — vertical push/pull
Detection: filtVertDiff ≥ 1.8g or STA/LTA ≥ 4.0, sustained 2s
Response: WARNING banner + 20s countdown

🌍 S-WAVE (Secondary)

Speed: ~3–4 km/s
Motion: Shear — horizontal side-to-side
Detection: filtHorizMag ≥ 2.2g, sustained 2s
Response: EARTHQUAKE! modal + full alarm

⚙️ System Architecture

01
📡
Hardware Node
ESP32 + MPU6050 at 10Hz. STA/LTA on Z-axis. UDP throttled: NORMAL 2s, WARNING 2s, EARTHQUAKE 5s.
02
🧠
Edge Logic
5-state machine: NORMAL → DETECTING → PWAVE → SWAVE → CALMING. One-shot beep flags prevent repeat alarms.
03
🐍
Middleware
Python receiver with 10s cooldown per status — double-layer flood protection keeps DB rows manageable.
04
🖥
Dashboard
Alert modal shows once per event via alertModalActive flag — no re-fire on every 3s refresh.
