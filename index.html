🌍 About SeismoGuard AI

SeismoGuard is an academic IoT capstone project designed to act as a real-time early warning system for seismic activity. It utilizes edge computing on ESP32 hardware to filter sensor noise and instantly transmit critical data over a local network to this monitoring dashboard.

The system classifies ground motion into three levels — NORMAL, WARNING, and EARTHQUAKE — and provides visual, audio, and database-logged alerts for each event.

⚙️ System Architecture

The four-layer pipeline processes raw accelerometer data into actionable seismic intelligence:

01
📡
Hardware Node
ESP32 + MPU6050 measures 3-axis acceleration at 15Hz and computes motion magnitude.
02
🧠
Edge Logic
On-device threshold evaluation. Local buzzer + LED alarm. UDP packet broadcast.
03
🐍
Middleware
Python UDP listener commits WARNING and EARTHQUAKE events to MySQL database.
04
🖥
Dashboard
This interface: live waveform, gauge, charts, CSV export, and audio alerts.

📏 Detection Thresholds

The ESP32 uses the following differential acceleration thresholds to classify seismic events:

Diff < 0.3
NORMAL — No Action
0.3 ≤ Diff < 0.8
WARNING — Minor Motion
Diff ≥ 0.8
EARTHQUAKE — Critical Alert
